
# digital-literacy-small-biz

A lightweight, mobile-responsive web application designed to assess digital tool adoption, UPI transaction failures, and cyber scam vulnerabilities among local small business owners. This project features a native Telugu user interface optimized for seamless, real-world field data collection.

## 🚀 Features
- **Telugu UI:** Tailored language styling for comfortable communication with local shopkeepers.
- **Mobile First:** Responsive layout optimized for field surveys on smartphones.
- **Offline Resilient:** Uses browser `localStorage` to save field entries securely without an internet database connection.
- **Data Export:** Instant download of responses into a structured CSV format ready for Excel analytical charts.

## 📁 Repository Structure
- `survey.html` - The unified single-file HTML, CSS, and JavaScript application.
- `README.md` - Documentation of the project scope and operations.

## 🛠️ How to Run Locally
1. Clone this repository or download the `survey.html` file.
2. Double-click `survey.html` to open it in any web browser on your phone or computer.
3. Conduct interviews, fill the form, and tap **"డేటా సేవ్ చేయండి" (Save Data)**.
4. Click **"Excel/CSV డౌన్‌లోడ్ చేయండి" (Download CSV)** at the end of the survey drive to export your data.

## 👥 Scope & Impact
Developed as part of a 14-day community digital literacy project to bridge tech adoption gaps and identify primary operational bottlenecks in micro-retail ecosystems.
